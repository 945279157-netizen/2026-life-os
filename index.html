数据同步

读取中…

档案的全部内容存在仓库的 data.json 里。在这个页面增删改，会先存在这台设备上； 点「同步到 GitHub」写回仓库后，手机、电脑、任何人打开链接看到的都是最新的。

GitHub 设置

建议用 Fine-grained personal access token：github.com/settings/personal-access-tokens → Repository access 只勾选 2026-life-os 这一个仓库 → Permissions 里把 Contents 设为 Read and write。 这样即使令牌泄露，也只能改这一个仓库。
令牌保存在浏览器本机存储里，只在你点同步时直接发给 GitHub。公用电脑上用完记得点「清除本机 Token」。
